# Stack

Реализация стека на чистом C (стандарт C11) с защитой от переполнения.

## Особенности
- Динамическое расширение при переполнении
- Проверка ошибок (переполнение/недостаток памяти)
- Логирование операций (push/pop)
- Поддержка разных типов данных через `union`

## Использование
```c
#include "stack.h"

Stack s;
StackInit(&s, sizeof(int));  // Инициализация

int x = 42;
StackPush(&s, &x);  // Добавление элемента
StackPop(&s, &x);   // Извлечение элемента

StackFree(&s);      // Очистка памяти
```

## Сборка
gcc -std=c11 stack.c main.c -o stack
